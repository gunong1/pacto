# AI 지급자·수령자 평가 — 실행 안내 (개발자가 아니어도 됩니다)

계약서에서 **누가 누구에게 돈을 내는지(지급자·수령자)**, **보증금인지 일반 금액인지**를 AI가 맞게 읽는지,
그리고 **근거가 부족할 때 PACTO 서버가 방향(출금·입금)을 마음대로 정하지 않는지** 확인합니다.

- 평가에 쓰는 계약서는 전부 **가짜**입니다 (`scripts/eval/moneyFlowCases.ts`, 9건 · 금액 18개). 실제 계약서·개인정보는 넣지 않습니다.
- 운영과 **같은 지시문·같은 모델·같은 서버 정리 규칙**을 씁니다. 다만 PDF 대신 같은 내용의 글을 보냅니다 (파일 읽기 정확도는 이 평가 범위 밖).
- **운영 서버·운영 DB를 쓰지 않습니다.** Supabase 프로젝트가 없어도 됩니다. 필요한 것은 OpenAI API 키뿐입니다.
- 실제 AI를 부르므로 **약간의 비용**이 듭니다 (9건 × 실행 횟수). 정확한 금액은 알 수 없습니다 — OpenAI 사용량 화면에서 확인하세요.

## 실행 순서 (Windows PowerShell)

```powershell
cd C:\Users\김지은\pacto\pacto
git pull
npm install

# 1) 키 없이 세트만 확인 (비용 0, 검증 아님)
npx tsx scripts/eval-money-flow.ts --dry-run

# 2) 키를 이 PowerShell 창에만 넣기 (채팅·파일에 붙여넣지 마세요)
$env:OPENAI_API_KEY = "여기에-키"

# 3) 실제 평가 (1회). 흔들림을 보려면 --runs 3
npx tsx scripts/eval-money-flow.ts --out money-flow-result.json

# 4) 끝나면 키 지우기
Remove-Item Env:OPENAI_API_KEY
```

`money-flow-result.json`에는 계약서 원문과 키가 들어가지 않습니다. 이 파일(또는 화면에 나온 표·지표)을 공유해 주시면 결과를 분석합니다.

## 결과 읽는 법

| 지표 | 뜻 | 기대 |
|---|---|---|
| 계약서가 밝힌 지급자·수령자 정확도 | "임차인은 임대인에게 지급"처럼 문장이 있을 때 맞게 읽었는지 | 높을수록 좋음 |
| 근거 없는 금액에서 역할을 비워 둔 비율 | 누가 내는지 문장이 없을 때 비워 두었는지 | 100%에 가까울수록 좋음 |
| ⚠ 근거 없이 역할을 채운 금액(추측) | 문장이 없는데 AI가 역할을 넣은 건수 | 0 |
| 돈의 성격 정확도 | 보증금(돌려받을 돈) / 일반 금액 구분 | 높을수록 좋음 |
| 서버 규칙 적용 후 방향 정확도 | 렌탈·구독·대출처럼 사용자가 언제나 한쪽인 계약만 방향이 정해지고, 그 밖은 "확인 필요" | 100% |
| ⚠ 방향을 정하면 안 되는데 정한 금액 | 임대차·근로·매매·용역에서 사용자 역할을 모르는데 출금·입금으로 정한 건수 | **0이어야 함** |

- 호출 오류가 1건이라도 있으면 그 실행은 **검증 완료가 아닙니다.**
- "추측"이 나오더라도 방향은 서버가 사용자 역할 확정 전까지 "확인 필요"로 둡니다. 다만 역할 추천 화면에 잘못된 지급자가 보일 수 있어 개선 대상입니다.

## 테스트 환경 검토 (Supabase)

이 평가는 Supabase 없이 돌아갑니다. 실제 PDF 업로드 → 민감정보 가림 → AI 분석까지 **전체 흐름**을 실제 AI로 확인하려면 아래 중 하나가 필요합니다.

| 방법 | 필요한 것 | 장점 | 주의 |
|---|---|---|---|
| A. 내 PC 로컬 Supabase | Docker Desktop, `npx supabase start`, `supabase/functions/.env`에 키 | 운영과 완전히 분리, 비용은 AI 호출뿐 | Docker Desktop 설치 필요, PC 사양에 따라 느릴 수 있음 |
| B. 별도 테스트용 Supabase 프로젝트 | 새 프로젝트 생성 + 마이그레이션·함수 배포 + 키 등록 | 실제 휴대폰 앱(테스트 빌드)으로 확인 가능 | 프로젝트 관리 부담, 무료 한도 확인 필요 |
| C. 운영 프로젝트 | — | 준비 불필요 | **별도 승인 전에는 사용하지 않음** (실제 계약서 분석을 위한 운영 함수 배포는 따로 승인) |

현재 테스트용 Supabase 프로젝트가 있는지는 알 수 없습니다. 있다면 알려 주세요.
